About

A backend engineer who likes systems with moving parts

I am a final-year Computer Science & Engineering student at North South University, graduating in October 2026. Most of my work sits on the server side: role-based web applications in Flask with MongoDB, REST APIs, and schema design that has to survive real query patterns.

The projects I enjoy most are the ones where the network is part of the problem. LabDesk pairs an Electron client with an embedded Express and Socket.IO server, streams screens peer-to-peer over WebRTC, and locks down exam machines at the operating-system level. Getting that to restore a safe state every time taught me more than any lecture did.

Alongside that I work on applied AI: retrieval-augmented assistants over local documents, and deep-learning pipelines for medical imaging and instance-aware object removal. I care about the boring parts — latency, memory, class imbalance, and whether the thing is honest about what it does not know.

LabDesk

LAN classroom and lab management platform for Windows

ElectronSocket.IOWebRTCExpressSQLite
  • Built the frontend and backend of a lab-management suite, pairing an Electron client with an embedded Express and Socket.IO server over SQLite so an instructor can monitor and remotely control every student workstation from one console.
  • Moved screen streaming to peer-to-peer WebRTC, which removed the server as a relay bottleneck during concurrent classroom broadcasts.
  • Wrote an exam-lockdown mode with URL blocking, USB and Bluetooth locks and application whitelisting, backed by a SYSTEM-level scheduled task that guarantees the machine returns to a safe state. Agentic AI for classroom automation is being added now.

Undergraduate thesis

Removing people from photographs, and proving it worked

Instance-aware object removal and background reconstruction

CSE 498R, directed research

YOLOv8Segment AnythingLaMaPython

A hybrid inpainting pipeline that removes people from crowded real-world scenes one instance at a time, rebuilding the background as it goes. To measure how complete a removal really is, I introduced a residual-aware metric that runs object re-detection over the reconstructed image instead of trusting pixel similarity alone.
